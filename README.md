# T2.2-Fase1APE4

## Introducción a la Programación Orientada a Objetos en Java

### Ejercicio 1: Notas del curso
Crear la clase Estudiante con los atributos nombre, nota1, nota2, nota3 y promedio. En main, crear 5
instancias, calcular el promedio de cada una e imprimirlas una debajo de otra con el formato nombre :
promedio, agregando Aprobado (7 o más), Supletorio (de 5 a 6.99) o Reprobado (menos de 5). Al
final, imprimir cuántos estudiantes aprobaron.

### Ejercicio 2: Inventario de una tienda
Crear la clase Producto con nombre, precio y stock. Crear 4 productos e imprimirlos con el formato
nombre : precio. Simular la venta de 3 unidades de dos de ellos, mostrar “Reponer” junto a cada
producto que quede con menos de 5 unidades e imprimir el valor total del inventario (suma de precio por
stock).

### Ejercicio 3: Veterinaria
Crear la clase Mascota con nombre, especie, edad y peso. Crear 3 mascotas e imprimirlas con el
formato nombre : especie : peso, mostrando “Revisar peso” si pesan más de 20 kg. Luego escribir
Mascota m4 = m1;, sumar 1 a m4.edad, imprimir m1.edad y explicar en un comentario por qué cambió.

### Ejercicio 4: Cuenta de ahorro
Crear la clase Cuenta con titular y saldo. Crear 2 cuentas, una con 200 y otra con 350. Con un while,
depositar 50 por mes en cada cuenta hasta que llegue a 500, imprimiendo cada mes con el formato titular
: saldo, y al final cuántos meses necesitó cada una (6 y 3).

### Ejercicio 5: Biblioteca
Crear las clases Libro (titulo, autor, disponible) y Socio (nombre, librosPrestados). Crear 4 libros y 2
socios, registrar que el primer socio presta 2 libros y el segundo presta 1 (disponible = false y aumentar
librosPrestados), y al final imprimir cada libro con el formato titulo : Disponible o titulo : Prestado,
cada socio con el formato nombre : librosPrestados y cuántos libros quedan disponibles.
